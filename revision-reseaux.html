Protocole IPv4

⚙️ Principes et Fonctionnement

  • Livraison sans connexion : Transmission sans garantie ni lien préalable
  • Principe de sauts : Les paquets passent de routeur en routeur, chemins différents possibles
  • Ordre d'arrivée : Aucune garantie d'ordre de réception
  • Plan d'adressage : Chaque nœud identifié par une adresse unique

🏗️ Structure et Identification

Format : 4 octets (32 bits) en notation décimale pointée
Exemple : 132.148.67.2
  • NetID : Numéro de réseau logique
  • HostID : Adresse d'hôte
  • Analogie : Réseau = nom de rue, Hôte = numéro dans la rue
Identification binaire : • Classe A : Commence par 0 • Classe B : Commence par 10 • Classe C : Commence par 110

📊 Classes d'Adresses

Classe 1er Octet Masque Bits R/H Capacité
A 1-126 255.0.0.0 (/8) 7/24 2²⁴ - 2
B 128-191 255.255.0.0 (/16) 14/16 2¹⁶ - 2
C 192-223 255.255.255.0 (/24) 21/8 2⁸ - 2
⚠️ Règle du -2 : On retire la 1ère adresse (réseau) et la dernière (broadcast)

🎭 Le Masque et CIDR

  • Rôle : Distinguer partie réseau de partie hôte
  • Calcul binaire : Bit à 1 = réseau, bit à 0 = hôte
  • Calcul du Réseau : RL = IP ET MASQUE
  • Notation CIDR : /n où n = nombre de bits à 1
Exemple : 255.255.255.248 = /29 (29 bits à 1 dans le masque)

🎯 Adresses Spécifiques

  • Boucle locale : 127.0.0.0 (réseau) / 127.0.0.1 (carte)
  • Broadcast : Tous les bits hôtes à 1
  • Réseau courant : Tous les bits hôtes à 0
  • Adresses Privées (RFC 1918) :
    • 10.0.0.0 - 10.255.255.255 • 172.16.0.0 - 172.31.255.255 • 192.168.0.0 - 192.168.255.255
  • APIPA : 169.254.0.0/16 (quand DHCP introuvable)

Codage & Architecture

💡 Bases de l'Information

L'ordinateur ne traite que des états binaires (0 ou 1)
  • Bit : Unité élémentaire
  • Octet (Byte) : 8 bits
  • Mot : Groupement de bits (16, 32 ou 64)

🔢 Systèmes de Numération

Système Base Symboles Conversion
Décimal 10 0-9 -
Binaire 2 0, 1 -
Octal 8 0-7 1 chiffre = 3 bits
Hexadécimal 16 0-9, A-F 1 chiffre = 4 bits

📐 Structure d'un Octet

MSB (Most Significant Bit) ← Poids fort (2⁷ = 128) ↓ [ 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 ] ↑ LSB (Least Significant Bit) ← Poids faible (2⁰ = 1)
⚠️ Attention : Toujours repérer le MSB et LSB sur les schémas !
Exemple : 01000001₍₂₎ = 65₍₁₀₎ = 'A'

➖ Complément à 2 (Nombres Négatifs)

Méthode en 3 étapes :
  1. Écrire la valeur positive en binaire
  2. Inverser tous les bits (0→1, 1→0)
  3. Ajouter 1 au résultat
Exemple : -25 1. +25 = 00011001 2. Inv = 11100110 3. +1 = 11100111 ← Résultat

🎈 Virgule Flottante (32 bits)

Zone Taille Rôle
Signe 1 bit 0 (+) ou 1 (-)
Caractéristique 7 bits Exposant + Biais (64)
Mantisse 24 bits Chiffres après virgule

Format : M × BE (décalage de virgule pour normaliser)

🔤 Données Alphanumériques

  • ASCII : 7 bits (128 caractères) - Standard de base
  • EBCDIC : 8 bits (IBM)
  • Chaque caractère = valeur numérique (ex: 'A' = 65, 'C' = 67)

Fondamentaux Réseaux

🌍 Typologie des Réseaux

Type Description Portée
PAN Personal Area Network (Bluetooth) ~10m
LAN Local Area Network (Entreprise) 100m - quelques km
MAN Metropolitan Area Network (Ville) Ville
WAN Wide Area Network (Internet) Mondial
Norme : L'IEEE définit les standards des couches physiques

🏛️ Architectures

  • Poste à Poste (Peer-to-Peer) :
    • Pas de serveur dédié
    • Groupe de travail (Workgroup) sous Windows
    • Sécurité décentralisée
  • Client / Serveur :
    • Architecture hiérarchisée
    • Administration centralisée
    • Sécurité centralisée

🖥️ Dimensionnement Serveurs

Serveur de Fichiers : Beaucoup de RAM (cache), peu de CPU
Serveur d'Applications : Processeur puissant (exécute les programmes)
Architecture n-Tiers :
  1. Présentation (Interface utilisateur)
  2. Application (Traitements)
  3. Données (Bases de données)

⚙️ Services Réseaux

  • Fichiers : Stockage, transfert, synchronisation
  • GED : Gestion documents électroniques
  • GEIDE : GED + numérisation archives papier
  • Base de Données : SQL, Annuaires LDAP
  • Impression : File d'attente (spooler)
  • Messagerie : Email, agendas, Présence (SIP)

💿 Stockage

Type Description Caractéristiques
NAS Network Attached Storage Serveur de fichiers autonome, RAID
SAN Storage Area Network Réseau dédié, fibre optique, Zoning, LUN
LUN (Logical Unit Number) : Découpage logique vu comme disque local
Virtualisation : Plusieurs serveurs sur une machine physique

🔒 Sécurité D.I.C

1. Disponibilité (Availability) :
• RAID (disques)
• Onduleurs/UPS (électricité)
• Fibre optique (liaisons fiables)
2. Intégrité (Integrity) :
• CRC (Codes de Redondance Cycliques)
• Commit à deux phases (bases de données)
3. Confidentialité (Confidentiality) :
• Permissions fichiers
• Chiffrement
• Analyseurs : Wireshark, TCPDump

Sous-Réseaux & ARP

🎭 Masque de Sous-Réseau

Définition : 4 octets agissant comme filtre réseau/hôte
  • Structure : Bits à gauche = 1 (Réseau), Bits à droite = 0 (Hôte)
  • Opération : Réseau = IP ET MASQUE

📋 Classes à Connaître

Classe Masque par défaut
A 255.0.0.0 (/8)
B 255.255.0.0 (/16)
C 255.255.255.0 (/24)
⭐ Plage Privée Classe B :
172.16.0.0 à 172.31.255.255
(Indispensable pour exercices type "Dubois")

✂️ Segmentation

Pourquoi segmenter ?
• Performance : Éviter saturation et collisions
• Sécurité : Isoler machines sensibles
Méthode : Emprunter des bits à la partie hôte
Formule Cruciale : 2ⁿ - 2 Si on emprunte n bits : → 2ⁿ - 2 sous-réseaux Pourquoi -2 ? Bits tous à 0 ou tous à 1 = RÉSERVÉS

🔍 Protocole ARP

  • Principe : Trouve adresse MAC via diffusion (broadcast)
  • Frontière : Les routeurs bloquent les broadcasts ARP (Couche 2)

⚠️ Attaques ARP

1. ARP Spoofing/Poisoning :
Faux messages pour lier MAC attaquant à IP légitime

2. Man-in-the-Middle (MITM) :
Intercepter et modifier le trafic

3. Déni de Service (DoS) :
Saturer les tables ARP

🛡️ Contremesures

  • DAI (Dynamic ARP Inspection) : Filtrage sur switchs
  • VLANs : Segmentation pour limiter portée attaque
  • ARPwatch : Surveillance et détection anomalies
